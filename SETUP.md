# Quick Setup Guide

## 1. Environment Setup

Copy `.env.example` to `.env` and fill in your credentials:

```bash
cp .env.example .env
```

Required variables:
- `VITE_SUPABASE_URL` - Your Supabase project URL
- `VITE_SUPABASE_ANON_KEY` - Your Supabase anonymous key
- `SUPABASE_SERVICE_ROLE_KEY` - Your Supabase service role key (for migrations)
- `VITE_SUI_NETWORK` - Sui network (testnet, devnet, or mainnet)
- `VITE_SUI_PACKAGE_ID` - Your deployed Sui package ID (after deploying contracts)

## 2. Database Setup

### Run Migrations via Supabase Dashboard

1. Go to https://supabase.com and create a new project
2. Navigate to SQL Editor in your Supabase dashboard
3. Open `supabase/migrations/20240101000000_initial_schema.sql`
4. Copy and paste the entire SQL content
5. Click "Run" to execute

This will create all necessary tables:
- `user_profiles` - User account information
- `achievements` - Achievement records
- `peer_tags` - Peer verification tags
- `friendships` - Friend connections
- `comments` - Achievement comments
- `reactions` - Likes and reactions
- `notifications` - User notifications

## 3. Sui Move Contract Deployment

### Install Sui CLI

```bash
cargo install --locked --git https://github.com/MystenLabs/sui.git --branch main sui
```

### Build and Deploy

```bash
cd sui
sui move build
sui client publish --gas-budget 10000000
```

Copy the `Published object ID` from the output and update `VITE_SUI_PACKAGE_ID` in your `.env` file.

## 4. Install Dependencies

```bash
npm install
```

## 5. Run Development Server

```bash
npm run dev
```

Visit http://localhost:5173

## 6. Slush Wallet Integration

The app includes placeholder functions for Slush Wallet. To integrate:

1. Install the Slush Wallet SDK when available
2. Update `src/lib/sui.ts` with the actual connection logic
3. The wallet connection will work through the `connectSlushWallet()` function

## Troubleshooting

### Database Connection Issues

- Verify your Supabase URL and keys are correct
- Check that migrations have been run successfully
- Ensure Row Level Security (RLS) policies allow access

### Sui Contract Issues

- Verify the package ID is correct in `.env`
- Check that contracts are deployed to the correct network
- Ensure you have Sui test tokens for gas

### PWA Not Working

- PWA features require HTTPS in production
- Service worker is automatically generated by Vite PWA plugin
- Icons need to be replaced with actual PNG files
